    Por dentro: a árvore rubro-negra de cada sala

    Cada sala guarda suas reservas numa árvore rubro-negra, ordenada pelo horário de início. Para saber se um horário está livre, o sistema olha só o vizinho anterior e o seguinte nessa árvore, em vez de percorrer todas as reservas. Cada círculo é uma reserva. O texto mostra só a hora de início, mas a ordem da árvore considera também o dia; passe o mouse sobre um círculo para ver a data completa.
